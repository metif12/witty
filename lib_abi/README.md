`lib_abi` translates Ghostty's `src/lib/{enum,struct,union}.zig` factories as a build-time generator. Run it before compiling users of the resulting declarations:

```
v -path '/path/to/witty|@vlib|@vmodules' run tools/lib_abi_generate schema.json output-directory
```

The JSON schema describes native types, enum keys (with `removed: true` representing the source null key), reflected struct fields, and named union variants. The generator writes actual `types.h` and `types.v` declarations. C struct/union types carry their layout directly; V declarations refer to those C types. C holes retain their ordinals, native enum holes compact, struct fields retain their types/defaults/alignment, union payloads select a container type's C projection, nested `cval` calls convert the corresponding payload, and each tag has a native `NameTagValue` alias. An emitted C static assertion enforces the source padding size contract during compilation.

V cannot synthesize types with Zig's `@Type`, nor declare nested type members. Reflection descriptors are therefore explicit schema inputs; `reflect_type[T]` obtains the native declaration kind and `cval` presence, and accepts the source `Type.C` projection as a descriptor. Union field descriptors pair the original named tag with the V sum-type variant. The source `Value(tag)` compile-time lookup becomes one concrete native type alias per tag. Empty C enums use an `i32` alias with no generated keys, preserving their C integer ABI; V does not express an uninhabited integer enum. Native enums use the smallest V integer storage (`u8` minimum), retaining the source's exact logical bit count as metadata. Native struct outputs are V type aliases rather than Zig type identity; their underlying representation is retained. Empty native C placeholders use the C backend's zero-size empty-struct extension. The generator reports the source compiler's failures for extern tuples and comptime extern fields.

The generator is independent of application ABI specializations. Existing application declarations are not silently regenerated by this tool; a caller must use the generated types in its build. Schema names and native type declarations must be valid V/C declarations, and defaults must be represented as V expressions.

Run the native differential/compiled ABI fixture with:

```
python3 lib_abi/reference_probes/run.py /path/to/ghostty /path/to/zig /path/to/v
```

The probe copies the original four factory modules unchanged to a temporary directory. It checks hole ordinals, native backing metadata, struct defaults and alignment, tagged wrapper/payload sizes, nested conversion, native payload aliases and empty native placeholders. It also verifies the original extern tuple/comptime and insufficient-padding compilation failures, and compiles a generated insufficient-padding case that must fail the emitted static assertion. The current probe uses the repository's tested `aarch64-macos.14.0` Zig target; other target ABI execution remains a platform validation task.
